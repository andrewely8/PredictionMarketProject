The page: https://docs.kalshi.com/getting_started/quick_start_websockets described how to setup a web socket connection in python. Following this tutorial and making some slight changes, the program ./WebSocketsTutorial.py takes a list of market tickers, and constructs a file tracking the order book of those markets for the duration that the program is ran. 

This allows us to construct a high resolution snapshot of the orderbook over a markets lifespan. If we can collect this data for many different sports games, we can construct a historical database that has order book information. Kalshi's historical public database has limited data, not including the order book.

This historical database will allow us to implement strategies and "back test" them, rather than having to run tests during live events.
